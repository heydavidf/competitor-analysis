# Contributing

Thanks for your interest. This is a small project maintained by one person, so issues and small pull requests are the most helpful.

## Before you open a pull request

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Run the checks listed in [AGENTS.md](AGENTS.md) (the same commands CI runs in `.github/workflows/ci.yml`). They must pass.
3. A bug fix should come with a test that fails before the fix and passes after it.
4. Keep the change focused: one problem per pull request.
5. Keep examples fictional. Never attach real customer data, confidential research or copied third-party text to an issue or pull request.

## Using coding agents

Agent-written changes are welcome. Please read the diff yourself before submitting, and say in the pull request which agent you used.
